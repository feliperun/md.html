What mdhtml is

mdhtml is one self-contained document for humans and machines. You write Markdown; the toolchain ships a single .md.html file that carries the rendered document, the runtime, fonts, styles, assets, and the canonical Markdown source byte for byte. It opens from disk with no server, no network, and no build step for the reader.

How to create one

Write a Markdown file, then build it into a self-contained document:

mdhtml build document.md

This produces document.md.html.

How to publish

Publish the built document to get a short public URL:

mdhtml publish document.md

The service builds, security-audits, and publishes the document for you. Hosted documents are served from an isolated origin with strict security headers.

How to inspect

Audit a built document before publishing or sharing it:

mdhtml audit document.md.html

The audit reports a security verdict and diagnostics, so what you publish is what you verified.
